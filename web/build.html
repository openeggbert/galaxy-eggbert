Build Guide

CMake targets and renderer options for GalaxyEggbertCNA.

Game Target

CMake optionDefaultTargetRole
GALAXY_EGGBERT_BUILD_CNAONGalaxyEggbertCNAThe maintained game, built directly on CNA + Easy3D

Desktop OpenGL 3.3

cmake -S . -B build-cna-opengl3 \
  -DGALAXY_EGGBERT_BUILD_CNA=ON \
  -DCNA_GRAPHICS_RENDERER=OPENGL33
cmake --build build-cna-opengl3 --target GalaxyEggbertCNA -j2

Run the executable from build-cna-opengl3, because runtime asset paths are relative.

WebGL 2

emcmake cmake -S . -B build-cna-webgl2 \
  -DGALAXY_EGGBERT_BUILD_CNA=ON \
  -DCNA_GRAPHICS_RENDERER=WEBGL2 \
  -DCMAKE_BUILD_TYPE=Release \
  -DBUILD_TESTING=OFF
cmake --build build-cna-webgl2 --target GalaxyEggbertCNA -j2

Sibling Repository Path Overrides

VariableDefault
CNA_HOME${CMAKE_CURRENT_SOURCE_DIR}/../cna
EASY3D_HOME${CMAKE_CURRENT_SOURCE_DIR}/../easy-3d

What Links Into GalaxyEggbertCNA

  • CNA — the game framework
  • SHARP_RUNTIME
  • easy3d::easy3d (or the easy3d target)
  • The renderer target selected by CNA's CNA_GRAPHICS_RENDERER option
  • ${GE_SHARED_SOURCES} — the engine-independent world/data sources

Post-Build Asset Copy

Custom post-build commands stage this repository's Content/, worlds3d/, textures3d/, and avatars3d/ beside the native executable. Emscripten embeds the required directories into its generated .data bundle.

Additional Tool Targets

TargetPurpose
GenerateSampleWorld3DGenerates worlds3d/world001.vwr — engine-agnostic, no CNA link needed
VerifyBlupiMovementExercises the engine-independent Blupi controller headlessly

Running Tests

cmake --build build-cna-opengl3 -j2
ctest --test-dir build-cna-opengl3 \
  -E easy-gl-resource-smoke-tests --output-on-failure

GalaxyEggbertWorldsTests covers only the engine-agnostic Worlds/ data model (World, Chunk, Block, bit-packing, binary I/O) — no dependency on CNA or Easy3D.

Windows

Cross-compile from Linux using the MinGW-w64 toolchain file, or build natively on Windows. Build-dir convention: build-windows. 

cmake -S . -B build-windows \
  -DCMAKE_TOOLCHAIN_FILE=cmake/toolchains/mingw-w64.cmake
cmake --build build-windows -j2
