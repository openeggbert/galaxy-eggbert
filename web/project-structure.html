Project Structure

What lives where in the repository, checked against the tracked files on 2026-11-10.

The repository holds the game's code, its worlds and assets, the tools that make and check them, the plans and audit ledgers, and this website. CNA and cna-engine are not inside it: they are sibling checkouts found at ../cna and ../cna-engine (or wherever -DCNA_HOME and -DCNA_ENGINE_HOME point; see Build Guide).

galaxy-eggbert/
├── src/
│   ├── GalaxyEggbertCNA/    the application host (main.cpp, GalaxyEggbertGame*.cpp)
│   └── GalaxyEggbert/
│       ├── Game/            the game: simulation, renderers, HUD, menus, saving
│       ├── Editor/          the in-game 3D world editor
│       ├── Worlds/          the voxel container (engine-independent)
│       └── *.cpp            record codecs, HubDoors, BlockDefinitionRegistry
├── include/GalaxyEggbert/   public engine-independent headers (Worlds/, Def/, records)
├── tools/                   verifiers, generators, world and asset tools, QA scripts
├── tests/                   GoogleTest unit tests and the golden frames/trace
├── worlds3d/                the shipped .vwr worlds (81 files)
├── Content/                 2D assets: sprite sheets, backgrounds, sounds, music, demos
├── avatars3d/               3D models (CNA SkinnedModelEXT directories)
├── textures3d/              Galaxy's own 3D textures
├── worlds/                  five old text-format maps
├── mobile-eggbert-reference/ research notes on the original game
├── plans/                   active plan, per-world briefs, audit ledgers, evidence
├── docs/                    handbook/ and provenance/
├── android/                 Gradle project for the APK
├── cmake/                   CMake helpers, MinGW toolchain, web shells
├── packaging/               Linux bundle launcher and README, release notes, third-party list
├── web/                     this website
├── .github/workflows/       cna-ci.yml (build and test), pages.yml (website)
└── CMakeLists.txt, CURRENT.md, handoff.md, plan.md, ... (root documents, below)

The host: src/GalaxyEggbertCNA/

The thin application layer, namespace GalaxyEggbert::CNA. Until 2026-11-09 the game class was one very large GalaxyEggbertGame.cpp (about 8 400 lines); it is now split by topic into seven translation units that share one header. Line counts are approximate (2026-11-10).

Tests: tests/

  • tests/GalaxyEggbert/: GoogleTest suites for the world model and records (Worlds/WorldTests.cpp, ChunkTests.cpp, BitPackingTests.cpp, MoveObjectRecordTests.cpp, HubDoorsTests.cpp, ...), built as GalaxyEggbertWorldsTests.

Build and platform files

  • CMakeLists.txt: the game target GalaxyEggbertCNA, the verifiers, the tests, the Linux bundle and the Emscripten link options.
  • cmake/: CopyDirectoryIfDifferent.cmake (copies the asset directories next to the executable), toolchains/mingw-w64.cmake, web/shell-cna.html (the page around the web build).
  • android/: the Gradle project (app/build.gradle, gradlew, local.properties.template, SpeedyBlupiActivity.java).
  • packaging/: run-galaxy-eggbert.sh.in, README-linux-bundle.md, and the RELEASE_NOTES.md and THIRD_PARTY.txt that go into the release packages.
  • .github/workflows/: cna-ci.yml (Linux build and CTest with pinned siblings), pages.yml (deploys web/).
  • Doxyfile: the API documentation target GalaxyEggbertDocs (only when Doxygen is installed).
  • Build trees (build/, build-cna-opengl3/, build-cna-webgl2/, ...) are git-ignored.
