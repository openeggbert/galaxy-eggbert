Chunk

A 10 × 10 × 10 block cube stored as a local palette plus bit-packed palette indices, with optional sparse per-block metadata.

Location

Headerinclude/GalaxyEggbert/Worlds/Chunk.hpp (also declares ChunkBlockMetadataRecord)
Sourcesrc/GalaxyEggbert/Worlds/Chunk.cpp
Bit packinginclude/GalaxyEggbert/Worlds/BitPacking.hpp, src/GalaxyEggbert/Worlds/BitPacking.cpp
NamespaceGalaxyEggbert::Worlds

Purpose

A World is 1000 chunks. A chunk does not store 1000 raw 16-bit blocks; it stores the distinct block values it contains (its palette, up to 256 entries) and, for each cell, the index of its value in that palette, packed with as few bits as the palette size needs. Handcrafted worlds have few distinct blocks per 10³ region, so most chunks pack into 1-3 bits per cell. A chunk holds no mesh; meshes are runtime caches built by the TerrainRenderer.

The chunk also owns the sparse extra metadata of its cells: a list of ChunkBlockMetadataRecords, each a local cell index, a 16-bit type and a byte payload. This is where objects, BigDecor, tile turns, hint zones and player starts live in a saved world.

Palette and adaptive bit packing

  • A new chunk is all air: palette {Air}, 1 bit per cell, 16 packed 64-bit words.
  • setBlock() looks the value up in the palette and appends it if missing. When the palette grows past a power of two (2 → 3, 4 → 5, ... 128 → 129) every cell is re-packed at the wider width.
  • The width is bitsNeededForPalette(n): 1 bit for 1-2 entries, 2 for 3-4, 3 for 5-8, ... 8 for 129-256.
  • Cell i occupies bits [i * bits, (i + 1) * bits) of a little-endian stream of uint64_t words; a value may straddle two words. The word count is ceil(1000 * bits / 64).
  • The palette never shrinks during editing: a value that is no longer used stays in the palette (and is saved) until the chunk is rebuilt with fromBlocks().
  • A 257th distinct value throws std::runtime_error ("Chunk palette is full"). The header comments say std::out_of_range; the code throws runtime_error.

Local cell index, shared by packing and metadata:

linearIndex(x, y, z) = x + y * 10 + z * 100      // 0..999

ChunkBlockMetadataRecord has localBlockIndex (uint32_t), metadataType (uint16_t) and payload (std::vector<std::uint8_t>), and compares with ==.

Serialized form

A chunk payload is a 24-byte header (VCH1, version 2, chunk size, bits per block, flags, palette count, block count, packed data size, metadata size), the palette as raw uint16_t values, the packed words, and, when flag bit 0 is set, a BMD1 metadata section. read() validates every field (bits must match the palette size, word count must match, no trailing bytes in the metadata section). Byte tables are on The .vwr Format.

Usage

Game code normally goes through World, which splits world coordinates into chunk and local ones:

// src/GalaxyEggbert/Worlds/World.cpp, World::setBlock()
auto& target = chunk(chunkX, chunkY, chunkZ);
const auto oldRaw = target.getBlock(localX, localY, localZ).rawValue();
target.setBlock(localX, localY, localZ, blockValue);

Direct use appears in the tests and in round-trips through a stream:

Chunk chunk;
chunk.setBlock(1, 2, 3, Block::make(10));
std::ostringstream out(std::ios::binary);
chunk.write(out);
std::istringstream in(out.str(), std::ios::binary);
Chunk copy = Chunk::read(in);
