BlockMetadata

A typed helper for the four metadata bits inside a Block. It gives the bits no meaning of its own.

Location

Headerinclude/GalaxyEggbert/Worlds/BlockMetadata.hpp (header-only)
NamespaceGalaxyEggbert::Worlds

Purpose

Every Block carries a 4-bit metadata field (bits 3..0 of its raw value). BlockMetadata wraps that nibble with bit getters, setters and copy-with-change helpers, so that code does not do the masking by hand. The class deliberately defines no semantics: rotation, variant or on/off state would be a game decision.

Two kinds of "metadata"

The word is used for two different things in the world format. Do not mix them up:

Block metadata (this class)Sparse extra metadata
WhereInside the 16-bit block value, so inside the chunk palettePer-cell records in the chunk's BMD1 section
Size4 bitsAny byte payload up to 65 535 bytes, typed by a 16-bit id
APIBlock::make(type, metadata), Block::metadata()World::setBlockExtraMetadata(), collectExtraMetadata(), findBlockExtraMetadata()
Used by the game (2026-11-10)NoYes: objects (1), plate/fan turns (2), BigDecor (3), hint zones (4), object turns (5), legacy switch rows (6), player starts (7, 8)
Status. No world in worlds3d/ has a non-zero block metadata nibble, and outside its own tests and Block.hpp nothing in the code base uses BlockMetadata. It is a ready, tested building block, not a feature. Distinct values would also cost palette space: make(10, 0) and make(10, 1) are two palette entries.

Usage

using namespace GalaxyEggbert::Worlds;
const BlockMetadata m = BlockMetadata{}.withBit0(true).withBit2(true);   // 0b0101
const Block b = Block::make(10, m);
assert(b.blockMetadata().bit2());
