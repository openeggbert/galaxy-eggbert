Releases

Galaxy Eggbert 0.3.0: the packages for Windows, Linux, Android and the web, what they need, and how to install and run them.

Download Release 0.3.0 (2026-11-12) is published as a GitHub release of the repository, with its four packages, their checksums and the release notes. Earlier releases (0.2.0 the same day, 0.1.0 to 0.1.3 on 2026-11-11) are on the releases page; CHANGELOG.md lists what changed in each.

New in 0.3.0

  • Fifteen languages: besides English, French, German and Czech, the game speaks Slovak, Spanish, Italian, Polish, Brazilian Portuguese, Dutch, Hungarian, Romanian, Swedish, Russian and Ukrainian. It starts in the system's language; the main menu's flag and the Setup's Language button open a panel of the fifteen flags, and the choice is remembered.
  • The font has the letters these languages need, the Cyrillic ones too.
  • The 3D editor shows an edit at once, also in the large worlds.
  • Lava, lightning and wind no longer blink for a frame when dynamite changes the terrain near them.
  • The network game counts names and chat in letters, not bytes. A 0.3.0 game cannot play with a 0.2.0 one.

New in 0.2.0

  • The game in French, German and Czech beside English: the menus, the Setup, the help, the training hints, the 3D editor and the network game. It starts in the system's language; the Setup's button at the top right switches between the four and is remembered. The French uses Mobile Eggbert's own texts where it has them.
  • The font has the letters these languages need, and capitals keep their accents.
  • No more hitch when the terrain changes (dynamite cutting a saw, a drip or a fan): only the part of the world around the change is built again.
  • The network game carries names with accents. A 0.2.0 game cannot play with a 0.1.x one.

What a release contains

  • The whole campaign in 3D: the main hub, twelve theme worlds with their 64 missions, and the bonus world, played as in the original (Campaign & Worlds).
  • Three players with their own progress, and each player's own galaxy, which can be named, exported, imported and deleted (with a backup).
  • The 3D world editor, on keyboard and mouse, a gamepad or a touch screen.
  • Ten demos in the main menu, and the player's own recordings.
  • Speedy Blupi 2's network game for 2 to 4 players on a local network (Windows, Linux and Android).
  • Optional 3D effects (Off to Ultra), 2x textures, frame rates up to 240 fps, full screen, gamepad and touch controls, and the original cheats.

The version is kept in VERSION.txt at the repository's root; the main menu shows it with the build's date and time.

Check a download against the checksums before running it:

Windows

  • 64-bit Windows with OpenGL 3.3. Extract the zip and run GalaxyEggbert.exe; keep the folder together.
  • The package is cross-built on Linux (MinGW) and played under wine; it has not yet been tested on Windows itself.
  • The game is saved in %LOCALAPPDATA%\Galaxy Eggbert.

Linux

Requirements

  • x86-64 and glibc 2.38 or newer, for example Debian 13 or Ubuntu 24.04 and later. The program and its bundled libraries need 2.38 (C23 strtol symbols and the C++ runtime of GCC 14).
  • From the distribution: OpenGL drivers, FFmpeg (libavcodec, libavformat, libavutil, libswresample) and the C and C++ runtimes. SDL3, SDL3_image and SDL3_mixer are bundled.

Install and run

tar -xzf GalaxyEggbert-0.3.0-linux-x86_64.tar.gz
./GalaxyEggbert-0.3.0-linux-x86_64/run-galaxy-eggbert

The launcher enters its own directory and starts GalaxyEggbert with any arguments you give it, so the command-line flags in Running the Game work through it. Keep the extracted folder together: the program finds Content/, worlds3d/, textures3d/ and avatars3d/ next to it. The archive also holds LICENSE, THIRD_PARTY.txt, RELEASE_NOTES.md, VERSION.txt, README-Linux.md and the SDL licences in licenses/SDL/. It is a runtime bundle, not an AppImage. If the game does not start because a system library is missing, install your distribution's package for it.

Saved games

Settings, progress, an interrupted mission, recordings and custom worlds are kept in ~/.local/share/Galaxy Eggbert (or $XDG_DATA_HOME/Galaxy Eggbert), not in the extracted folder, so a new version can be unpacked anywhere. --user DIR chooses another folder. The files of an earlier build kept beside the game are copied there on the first start. See Save Data & Resume.

Android

  • Android 7.0 (API 24) or newer on an arm64 device. The APK is signed with the project's release key.
  • Install it as an app from outside a store (allow the installer when the phone asks). Its package id is org.openeggbert.galaxyeggbert, so it installs beside Mobile Eggbert instead of replacing it.
  • On the first start the game copies its data to the app's private storage, where its saves stay too.
  • The 2x textures are not in the APK; Android always uses the normal sheets.

Web

  • Serve the extracted folder over HTTP(S) (opening the file from disk does not work) to a browser with WebGL 2; the first start downloads about 100 MB. The game is saved in the browser's storage for the page.

Known limitations of 0.3.0

AreaLimitation
Linux, older systemsNo archive for glibc 2.35 (for example Ubuntu 22.04). It has to be built on such a system.
WindowsPlayed under wine, not yet on Windows itself.
AndroidPlayed on a phone, but gamepads have had little testing on real devices.
WebNo multiplayer in the browser.
MultiplayerPlayed between several instances on one machine and under wine, not yet between two real machines.
LanguagesGalaxy's own texts were translated for the game and wait for a native speaker's reading (the owner reads the Czech).

Licences

Galaxy Eggbert is free software under the GNU General Public License, version 3. The packages bundle CNA (Ms-PL), cna-engine (MIT) and SDL3, SDL3_image and SDL3_mixer (zlib). The 2D graphics, sounds and music come from Mobile Eggbert (MIT); Speedy Blupi and Speedy Eggbert are original creations of EPSITEC SA. The 3D models and the 2x graphics were converted and rendered from the original Ray Dream scenes, and the 3D worlds are Galaxy Eggbert's own designs. THIRD_PARTY.txt in each package has the details; Assets & Tools describes where each asset comes from.

Making the packages

tools/release/make_windows_zip.sh, make_web_zip.sh and make_release.sh build the packages from the Release build trees; the last also writes the checksums and prints the glibc version the Linux program needs (docs/releasing.md). See Build Guide: Release packages.
